### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1. Сейчас сервис депозитов синхронно ходит в сервис ставок за актуальными значениями ставок по депозитам. В качестве альтернативного решения можно рассмотреть асинхронное уведомление сервиса депозитов об изменении ставок по депозитам.
2. Если нагрузка на сервис депозитов будет очень большая, то можно предусмотреть кэширование ставок, чтобы сократить кол-во обращений к БД.
3. Система партнерского кол-центра может ходить в API сервиса депозитов за актуальными ставками. Но сейчас у системы нет возможность делать API-вызовы.

1. Так как хранилище со ставками обновляется периодически или могут быть ошибки обновления, то сотрудники какое-то время могут видеть неактуальные ставки по депозитам.
2. Есть ограничение, что системы кол-центров не могут ходить напрямую в API АБС.
